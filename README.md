Toxic Comment Classification - Social Media Mining (Indiana University Bloomington)

This project was completed as part of the Social Media Mining course at Indiana University Bloomington, taught by Professor Siqi Wu. The objective was to develop and evaluate two machine learning models for classifying social media comments as toxic or not toxic using a dataset of 4000 comments from Reddit, Twitter/X, and YouTube.

Project Overview:
Models Implemented:
Logistic Regression with TF-IDF
Fine-Tuned BERT (Transformers)
Key Findings:
The fine-tuned BERT model outperformed Logistic Regression, achieving 81.5% accuracy with significantly better recall.
Logistic Regression struggled with detecting toxic comments due to class imbalance.
Files Included:
Report documenting methodology, results, and insights.
Jupyter Notebook with full implementation and reproducibility.
Prediction CSV with model outputs on the test dataset.
Training and testing datasets used for model development and evaluation.
This project focused on NLP, text classification, and model evaluation, addressing challenges such as imbalanced data and contextual toxicity detection.
